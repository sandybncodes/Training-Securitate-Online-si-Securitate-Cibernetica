# Asset Sources

This project intentionally avoids random hotlinked imagery. The local assets below are generated or created for educational use and are included directly in the presentation bundle.

## Local assets

- `assets/images/hero-cinematic.svg` — handcrafted cinematic backdrop representing a dark digital environment.
- `assets/images/ai-visual.svg` — abstract AI network concept illustration.
- `assets/images/classroom-safety.svg` — warm, human-centered classroom safety concept.
- S01 key visual is built in HTML/CSS (phone, lock screen, fictional "Banca Exemplu" notification); `hero-cinematic.svg` is no longer used on S01. A real photograph is still wanted (see `docs/ASSET_TODO.md`).

## Vendored third-party files (offline use)

- `assets/vendor/bootstrap/bootstrap.min.css` — Bootstrap 5.3.3, MIT License.
- `assets/vendor/fonts/inter-latin-wght-normal.woff2`, `inter-latin-ext-wght-normal.woff2` — Inter variable font from `@fontsource-variable/inter` 5.1.0, SIL Open Font License 1.1.

## License status

All include files are created locally for this educational project and do not use third-party copyrighted imagery or stock photographs without proper permission.

## Additional notes

- No autoplaying video or embedded media is included.
- No real logos, bank branding, or personal student data are used.
- The project remains suitable for a classroom environment and static deployment.
